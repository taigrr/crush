Launch a new agent that has access to the following tools: glob, grep, ls, view. When you are searching for a keyword or file and are not confident that you will find the right match on the first try, use the agent tool to perform the search for you. Pass `model` to run it on a specific model: a configured role name (`large`, `small`, `worker`, or a user-defined role), `provider/model`, or a bare model id. Omitted runs the configured `worker` role, else the large model. Prefer a cheap model for mechanical searches.
